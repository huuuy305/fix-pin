# Pin95 Improved

Cosmetic-only Roothide tweak for iOS 18.

Features:
- Replaces visible battery health `70%` with `95%`.
- Hides common non-genuine battery warning labels in Vietnamese and English.

Important:
- This does not change the real battery health.
- This does not make the battery genuine.
- iOS layout changes may leave a small blank area where the warning was.
